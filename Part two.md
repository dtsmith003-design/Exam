# University Portal

CSC 305 Final Project - Part 2

## Description
This project uses Node.js, Express, Pug, and SQLite to display university information for students, faculty, and the registrar.

## Setup
1. Download `univdb.sqli` from Canvas.
2. Place the database file in the project folder, next to `app.js`.
3. Run `npm install` in the terminal.
4. Run `node app.js`.
5. Open http://localhost:3000 in your browser.

## Features
- Student Dashboard: Displays enrolled courses, grades, and Winter 2026 course offerings.
- Faculty Dashboard: Displays courses assigned to a faculty member.
- Registrar Dashboard: Displays Winter 2026 course offerings.
